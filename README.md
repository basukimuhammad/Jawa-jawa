# JawaScript Playground

Playground JawaScript untuk Vercel.

## File utama
- `app.jawa` — aplikasi/source utama.
- `src_translator.js` — translator keyword JawaScript ke JavaScript.
- `api/index.js` — adapter Vercel dan runtime untuk tombol Jalankan.

Tidak ada `app.generated.js`. Kode `.jawa` diterjemahkan saat runtime ketika user menekan Jalankan.

## Deploy
Import repository ini ke Vercel lalu deploy. Gunakan Node 24.x.
